# Final 7–10 minute Demo Script

1. Open CampusPulse and log in as a student.
2. Show dashboard counts.
3. Report a sample issue: “Wi-Fi not working”.
4. Open Issues and upvote it once.
5. Log in as admin and change status to IN_PROGRESS/RESOLVED.
6. Show GitHub repository: Jenkinsfile, Dockerfiles, Compose file.
7. Open Jenkins and show the stage graph and build history.
8. Change a harmless UI label, commit and push.
9. Do not click Build Now. Show GitHub webhook activity and Jenkins auto-trigger.
10. Show Checkout → Install → Lint → Test → Build → Docker Build → Deploy → Smoke Test.
11. Refresh CampusPulse and show the change.
12. For failure demo, temporarily add a deliberately failing Jest assertion, push it, show the pipeline stopping at Test, revert/fix, push again and show successful deployment.
