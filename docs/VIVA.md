Best demo explanation:
“CampusPulse is deliberately simple at the application layer. The key engineering contribution is that a Git push automatically travels through GitHub and Jenkins, is validated with linting and automated tests, is packaged into Docker images, deployed with Docker Compose, and verified through a health check. A failing test blocks deployment.”
